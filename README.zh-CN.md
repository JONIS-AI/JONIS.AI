## 我构建什么

<details>
<summary><strong>01 · AI Engineering</strong> — 智能体、自动化与 LLM 应用</summary>

<br/>

从原型到生产：智能体、RAG、语音、集成与流水线，减少重复性工作并推动营收增长。

`智能体` `RAG` `自动化` `语音` `API` `微调`

</details>

<details>
<summary><strong>02 · 3D Sites</strong> — 具备产品级性能的沉浸式网页</summary>

<br/>

WebGL、Three.js、着色器与有意图的动效。在不牺牲速度、可访问性与转化率的前提下，实现高冲击力的沉浸体验。

`Three.js` `WebGL` `GLSL` `动效` `性能` `60fps`

</details>

<details>
<summary><strong>03 · XaaS</strong> — 平台与订阅制产品</summary>

<br/>

从架构到计费，从引导到仪表盘。为可预测扩展而设计的软件即服务。

`SaaS` `平台` `计费` `仪表盘` `基础设施` `规模`

</details>
